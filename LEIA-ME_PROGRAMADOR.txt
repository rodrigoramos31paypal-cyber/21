21 DIAS DE FOCO — VERSÃO PARA O PROGRAMADOR
Data: 5 de novembro de 2026
Pasta: 21dias-v3/

ESTE É O PROTÓTIPO FUNCIONAL MAIS RECENTE.
Contém o design, fluxo, onboarding, alimentação, modo escuro e estrutura de admin.

FICHEIROS PRINCIPAIS
- index.html          → estrutura da app (landing, dia, plano, alimentação, admin)
- estilos.css         → design (preto/verde/branco + modo escuro)
- app.js              → lógica de navegação, onboarding, progresso, tema, admin
- conteudos.js        → dias, exercícios dos 3 percursos, textos
- server.py           → servidor Flask + SQLite (apenas para testes locais)
- assets/             → foto João Pedro, 21 cartões diários, 3 PDFs, ícones
- manifest.webmanifest → PWA básico
- foco.db             → base de dados de teste (pode ser apagada)

COMO TESTAR LOCALMENTE
1. pip install flask flask-cors
2. python3 server.py
3. Abrir http://localhost:8080
4. Para admin: adicionar ?admin=1 ao URL ou clique direito no logo “21”
